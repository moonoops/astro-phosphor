# Room Backdrop Calibration Reference

Quick reference for measuring pixel coordinates, building `glassPath`/`rasterPath`, and running `scripts/prepare-room.mjs` in **Astro Phosphor**.

---

## 1. Quick Coordinate Measurement Script

Run this snippet (via `node -e`) to verify image dimensions, aspect ratio (`1672:941`), and convert measured master pixels into `1672 × 941` coordinates:

```mjs
import sharp from 'sharp';

const file = 'src/assets/room-originals/afternoon.png';
const { width, height } = await sharp(file).metadata();
const ratioDiff = Math.abs(width / height - 1672 / 941);
console.log({ width, height, recommendedWidth: width >= 2508, ratioDiff: +ratioDiff.toFixed(5) });

// Convert a rectangle measured in native pixels -> 1672x941 logical units
const toLogical = (x, y, w = 0, h = 0) => ({
  x: +(x * 1672 / width).toFixed(2),
  y: +(y * 941 / height).toFixed(2),
  width: +(w * 1672 / width).toFixed(2),
  height: +(h * 941 / height).toFixed(2),
});

console.log('Example aperture:', toLogical(1896, 870, 1140, 855));
```

Recommended exact multiples of `1672 × 941`:
- **`3344 × 1882`** (2×) — crisp desktop standard
- **`5016 × 2823`** (3×, current master) — ideal for 2× Retina close-zoom

## 2. Constructing `glassPath` and `rasterPath` (`src/geometry/tube.ts`)

Both paths live in local aperture coordinates `0..W` × `0..H` (where `W = aperture.width`, `H = aperture.height`):

- **`glassPath`**: Traces the inner glass rim meeting the plastic bezel. Four gently bowed quadratic curves (`Q`) joined by cubic corner fillets (`C`). Used by `<clipPath id="tube-aperture">` (normalized by `scale(1/W, 1/H)`).
- **`rasterPath`**: Inset slightly (`~4–6` logical units inside `glassPath`, slightly larger corner radius) to create the realistic dark phosphor shoulder. Used by `<mask id="tube-raster">` (Phosphor) and `<mask id="tube-raster-tight">` (scaled `1.014 × 1.018` for Rainbow/Coffee/CLI/Pixel), and sampled by `createPhotographedLens()` in `src/geometry/signal-lens.ts` to compute the barrel-curvature displacement map.

### Flat / Straight-Edged Monitor Shortcut
If your new monitor is a flat-screen Trinitron or LCD with straight edges and corner radius `r` (e.g., `r = 6`):

```ts
// Local 0..W x 0..H rounded rect (zero edge bow -> minimal barrel distortion)
export const glassPath = `M ${r} 0 H ${W - r} Q ${W} 0 ${W} ${r} V ${H - r} Q ${W} ${H} ${W - r} ${H} H ${r} Q 0 ${H} 0 ${H - r} V ${r} Q 0 0 ${r} 0 Z`;
```
