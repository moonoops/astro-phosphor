## Overview

**Droy** is an open-source personal AI agent running directly on **Android 11+ devices**. By bundling an ARM64 DeepSeek Harness runtime inside the APK, it runs independently without cloud phones or tethered desktop ADB bridges — handling local memory, multi-space research, and cross-app GUI automation (`Android Use`).

## Architecture Highlights

```text
Kotlin / Jetpack Compose Native Client
 ├─ Dual Pipelines: Messages (Search / Memory / Voice) | Tasks (Android Use)
 └─ Global Floating Overlay (Live Progress / Follow-up Prompt / Emergency Stop)
                     │
     [ Embedded ARM64 DeepSeek Harness Runtime ]
      ├─ Routing & Extensions: Multimodal vision + UI tree fallback · Skills · MCP
      ├─ Local MemOS Memory: Per-space physical isolation on device
      └─ Progressive Capability Layers:
          ├─ Base (Zero privilege): Chat, offline ASR, local memory
          ├─ Execution (Accessibility): UI tree parsing, screenshots, gestures
          └─ Enhanced (Optional Shizuku / Root): System automation & notification triage
```

- **True On-Device Runtime**: Works untethered after initial model API configuration, supporting both multimodal screenshot reasoning and lightweight text-only UI-tree fallback.
- **Progressive Privilege Tiers**: Never demands Root upfront. Chat and local memory require zero special permissions; core cross-app automation works on non-root phones via Accessibility Services; Shizuku/Root remain opt-in enhancements.
- **Global Floating Control Layer**: Because mobile apps occupy the full screen, a lightweight floating bubble remains reachable across apps so you can inspect steps, answer mid-task questions, or hit emergency stop immediately.

## Key Trade-offs

1. **Separate Messages from Tasks**: High-privilege GUI automation activates only inside the Tasks space, preventing casual chat prompts from triggering unintended device actions.
2. **Interruptible state machine over fake autonomy**: Phone calls, login walls, CAPTCHAs, and payment prompts automatically suspend execution and hand control back to the user.
3. **Local-first privacy**: On-device speech recognition and isolated local memory keep sensitive personal context on your phone rather than syncing to a mandatory cloud service.
