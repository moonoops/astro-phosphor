## Overview

**Signal Kit** showcases the pure-frontend Web Audio and Canvas toolkit behind Astro Phosphor's `/games` arcade. Every sound cue is synthesized on the fly with zero external MP3 assets, and every game canvas adapts live across all five retro OS palettes.

## Key Features

- **Zero-Asset Web Audio:** Crisp 8-bit chiptune cues generated directly via Web Audio API oscillators with global mute respect.
- **OS-Aware Palettes:** Phosphor OS preserves authentic single-hue monochrome CRT graphics while Rainbow, Coffee, CLI, and Pixel render crisp color stages.
- **100% Offline Saves:** Best times, high scores, and Magic Tower's 4 save slots persist cleanly in `localStorage`.
