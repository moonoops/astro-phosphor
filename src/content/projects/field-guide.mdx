## Overview

**Field Guide** is a sample case study included with **Astro Phosphor**. Replace the MDX files under `src/content/projects/` with your own portfolio work — every entry automatically renders in `/work`, generates a stacked child window at `/work/[slug]`, and opens full-color media in the lightbox.

## Architecture Highlights

- **Three-Layer Separation:** Physical CRT hardware shell (Layer 1), isolated peer OS chrome and tokens (Layer 2), and reusable shared apps (Layer 3).
- **Zero-FOUC Persistence:** User OS, sub-theme, lighting scene, camera zoom, and Reading Mode preferences apply synchronously before first paint.
- **True-Color Lightbox:** Clicking any gallery image opens a full-color viewer above the CRT scanline layers.
